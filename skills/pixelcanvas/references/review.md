# 看圖檢查清單 + 症狀 → 修法

每輪渲染後逐項檢查，寫下 **2~4 個最嚴重的問題**，下一輪只修這幾個。

## 怎麼「看」

| 你有的能力 | 做法 |
|---|---|
| 能讀圖片 | 打開 `outputs/<name>_x0.5_preview.jpg`；細節用 `--crop` 或 `look.py grid` 的全解析度小圖 |
| 不能讀圖片 | `python tools/look.py report <png>`；細節用 `look.py crop` 裁出局部再 `report` 那張裁切圖 |
| 比較改動 | `look.py diff A.png B.png`（數字 + 熱圖）；`look.py compare A B`（並排，需要視覺） |

### 讀 `look.py report` 的數字

- **過曝(>0.98)**：> 3% 太亮（通常是太陽光暈太大或天空太亮）；> 0.3% 但集中在光源附近是正常的。
- **死黑(<0.02)**：> 5% 前景太黑、失去細節；夜景可以到 15%，但要確定是剪影而不是整片死黑。
- **整體對比(std)** 依題材而定（參考 gallery 的實測值）：白天 / 黃昏風景 0.18~0.28（mountains_sunset 0.24、
  sea_sunset 0.21）；夜景、大面積單色背景的靜物會低到 0.06~0.14（night_sky 0.09、still_life 0.06、city_dusk 0.14），
  這時改看**焦點格**的對比和 p99 —— 焦點要有明顯的亮點。白天風景 < 0.12 → 太灰；任何題材 > 0.32 → 太硬。
- **最亮 0.5% 像素的重心**：應該落在你設定的光源位置附近。分布範圍很大 → 亮的東西太多（雲、閃光過量）；
  例外是本來就散布全畫面的亮點（星空、城市窗燈）。
- **九宮格亮度**：大氣透視 → 遠景（通常中間列）應比近景（底列）亮、對比低；
  三列亮度差距 < 0.05 → 層次分不開。焦點格應該是對比最高或最亮的一格。
- **質感欄**：`平` = 幾乎沒細節（塑膠感 / 純漸層）；`粗糙` 出現在天空 → 噪聲 scale 太小或顆粒太多。
  天空應為 `平` 或 `細緻`，近景岩石 / 森林應為 `細緻` 或 `粗糙`。
- **主色**：前 2 名合計 > 70% → 畫面單調；檢查是否有預期的強調色（太陽、窗燈、紅球）。
- **色相**：0° 紅、30° 橙、60° 黃、120° 綠、180° 青、240° 藍、280° 紫、320° 粉紫 / 洋紅；s = 飽和度。
  「粉紫晚霞」≈ 地平線附近 300°~330°、s 0.2~0.4；「暖橙夕陽」≈ 20°~40°；s < 0.1 幾乎是灰。
- **垂直剖面**：亮度沿 V 的變化。天空通常往地平線變亮；地面 / 近景要比天空暗一截；某段突然變暗 = 山或樹林開始。
- **各欄最強的上下分界**：每欄列出最強的兩條明暗交界（V 位置、上亮下暗 / 上暗下亮、Δ）。
  應該對得上你設定的稜線 / 地平線高度；Δ < 0.05 → 那條邊界太弱，兩層會糊在一起。
- **局部檢查**：`look.py crop 圖 x0 y0 x1 y1 -o 暫存.jpg` 後再 `report 暫存.jpg`，例如只看雪地、只看某層山；
  九宮格的「質感」會把樹和雪混在一起算，裁出純雪地才準。
- **ASCII 亮度圖**：確認大結構：地平線高度、山的輪廓、光源位置、亮暗分區是否符合構圖。

## 清單

1. **曝光**：沒有大片死白（太陽光暈、天空）或死黑（前景）。`cv.stats()` 的「>1 比例」> 3% 通常就太亮。
   太陽要像「一顆亮點 + 光暈」，周圍天空要比太陽暗。
2. **大氣透視**：越遠越淡、越接近霧色、對比越低；近景對比高、顏色深。層與層之間分得開。
3. **光源一致**：山、雲、樹、物體的受光面都朝同一邊；影子方向相反；低角度光 → 剪影有 rim light。
4. **質感尺度**：噪聲 scale 太小 → 毛皮 / 雜訊感；太大 → 塑膠感。森林 / 雲用 plain / billow，岩石用 ridged。
5. **邊緣**：剪影有 1px 抗鋸齒；雲邊蓬鬆（閾值 smoothstep 寬一點）；物體與地面有接觸陰影。
6. **水**：倒影以眼平線鏡射；遠處接近全反射、近處透出深水色；閃光只在光源正下方。
7. **重複感**：相鄰物件不共用同一噪聲 / seed；隨機撒的物件大小、間距有變化。
8. **構圖**：焦點在三分線附近；前景框住畫面但不搶戲；地平線不要剛好在正中間（除非刻意對稱）。
9. **解析度一致**：草稿（0.5）和全尺寸看起來一樣（像素常數都乘了 S / `sc.px()`）。

## 症狀 → 修法

| 症狀 | 可能原因 | 修法 |
|---|---|---|
| 整片過曝、太陽一大坨白 | 光暈強度太高、sigma 太大、太陽盤太大 | 降 glow 強度（0.3 → 0.15）、縮小大光暈 sigma；`finish(knee=0.75)`；天空漸層靠太陽處調暗 |
| 畫面灰、霧濛濛 | 霧太多、近景不夠暗 | 近層 fog → 0~0.1；近景顏色更深；`contrast(0.12)`；`levels(0.03, 1, 1)` |
| 層次分不開 | 相鄰層顏色 / 霧量太接近 | 拉開 fog 差距（例 0.8 / 0.55 / 0.3 / 0.1）；遠層偏霧色、近層偏深色；層間加 `mist` |
| 雲像大理石 / 煙 | warp 太強、閾值太窄 | 降 warp（0.35 → 0.2）；閾值區間放寬；aspect < 1 讓雲橫向 |
| 雲像棉花糖 / 太糊 | softness 太大、缺少小尺度 | 降 softness；多加一個高頻 octave；受光面加細噪聲 |
| 近景太平、塑膠感 | 缺少中 / 小尺度紋理 | 加 relief / 高頻 fBm 調明暗（±10%）；加樹、草、岩石等小物件 |
| 毛皮感、雜訊感 | 噪聲 scale 太小或 octave 太多 | scale ×2；octaves 少 1~2；grain 降到 0.01 |
| 剪影鋸齒 | 用了硬閾值 `Y > ridge` | 改 `clamp01(Y - ridge + 0.5)`；形狀用 `shape_mask(aa=3)` |
| 物體像浮在空中 | 落影離開接觸點、缺 AO | 影子中心貼接觸點；加一道窄而深的接觸陰影 |
| 光源方向矛盾 | 各物件各自假設光向量 | 在檔案開頭定義一個 `L` / `light_dir`，所有物件共用 |
| 水面像塑膠板 | 倒影太清楚、沒有波紋 | 加橫向拉長的波紋位移；近處混入深水色；遠處亮、近處暗 |
| 閃光太密、像雜訊 | 閃光閾值太低、範圍太寬 | 只在光源正下方的直帶內；提高 smoothstep 閾值；越遠帶子越窄 |
| 重複、像磁磚 | 同一噪聲 / seed 用在多處 | 每層 seed 不同；offset 錯開；加低頻變化調制密度 |
| 摩爾紋（遠處閃爍條紋） | 透視紋理在遠處頻率過高 | 遠處用 `smoothstep` 淡出紋理振幅；或改用較低 octave |
| 草稿和全尺寸不一樣 | 像素常數沒乘 S | 所有 px 常數改成 `x * S` / `sc.px(x)`；數量型參數（星星數）不要隨解析度變 |
| 顏色髒、偏色 | 補色互相混合、飽和度過高 | 陰影偏冷 / 受光偏暖但別混在一起；大面積降飽和；`split_tone` 量 ≤ 0.1 |
